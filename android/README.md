# APEX AI Trading Lab — Android Package & Auto-Updater

- **Package ID:** `local.apex.tradinglab`
- **Web Bundle:** Compiled from `../frontend/dist` (`capacitor.config.json`)
- **Auto-Update Feed:** Checks `https://github.com/aliazizdbab/apex-ai-trading-lab/releases/latest` (and `/version.json`) directly from GitHub inside Settings → GitHub Auto-Updater and the top status bar.
- Download ready `.apk` builds from GitHub Releases: https://github.com/aliazizdbab/apex-ai-trading-lab/releases
