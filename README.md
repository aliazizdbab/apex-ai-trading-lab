# APEX AI Trading Lab

منصة بحث وتنفيذ تداول كريبتو (MEXC Spot) بالذكاء الاصطناعي.
الحالة الحالية: **المرحلة 1 (واجهة أمامية فقط)**. لا يوجد Backend ولا اتصال بـ MEXC بعد.

> كل ما يظهر في الواجهة موسوم **DEMO DATA** هو بيانات تجريبية لمعاينة الشكل فقط، وليس بيانات سوق حقيقية ولا أرصدة حقيقية. حالات الاتصال (MEXC / AI / Engine) تظهر "غير متصل" بصدق لأنه لا توجد خدمات خلفية بعد.

## المتطلبات (لتشغيل المرحلة 1)

- Node.js 20 أو أحدث (يُنصح بـ 22): https://nodejs.org
- Git (اختياري لكن موصى به)
- متصفح حديث (Chrome / Edge / Firefox)
- اتصال بالإنترنت أثناء `npm install`، وأيضاً لتحميل الخطوط (Inter وIBM Plex Sans Arabic) من Google Fonts. بدون إنترنت تعمل الواجهة بخطوط النظام.

Docker غير مطلوب في المرحلة 1. سيلزم من المرحلة 2.

## التشغيل على Windows (PowerShell)

```powershell
# 1) فك الضغط ثم ادخل مجلد الواجهة
cd apex-ai-trading-lab\frontend

# 2) تثبيت الحزم (مرة واحدة)
npm install

# 3) تشغيل بيئة التطوير
npm run dev
```

افتح المتصفح على: http://127.0.0.1:5173

## الأوامر المفيدة (داخل مجلد frontend)

| الأمر | الوظيفة |
|-------|---------|
| `npm run dev` | تشغيل الواجهة للتطوير |
| `npm test` | تشغيل اختبارات الوحدات (Vitest) |
| `npm run typecheck` | فحص TypeScript |
| `npm run build` | فحص الأنواع ثم بناء نسخة الإنتاج في `dist/` |
| `npm run preview` | معاينة نسخة الإنتاج |

**ترتيب التحقق الموصى به عند أول تشغيل:** `npm install` ثم `npm run typecheck` ثم `npm test` ثم `npm run dev`.
إن ظهر أي خطأ في أي خطوة، أرسله لي كما هو وسأصلحه قبل الانتقال للمرحلة 2.

## ما الذي يعمل فعلاً في المرحلة 1

- نظام التصميم (ألوان APEX، وضع داكن وفاتح، أرقام جدولية).
- الإنجليزية افتراضياً، وتبديل إلى العربية مع RTL كامل (من الترويسة أو صفحة الإعدادات). الاختيار يُحفظ في المتصفح.
- شريط جانبي قابل للطي (للشاشات الكبيرة) وتنقل سفلي + درج "المزيد" (للجوال) مع بحث في الوحدات.
- ترويسة: عنوان الصفحة، مؤشرات الحالة، بحث عام، الإشعارات، المظهر، اللغة، قائمة الحساب.
- **لوحة التحكم:** بطاقات المقاييس (تجريبية)، فصل صريح بين الحساب الحقيقي والورقي، جدول أسواق بالبحث والفرز والمفضلة وفتح الرسم.
- **محطة التداول:** رسم شموع (Lightweight Charts) بشموع تجريبية، الأطر الزمنية الخمسة عشر، OHLC عند تمرير المؤشر، حجم التداول، قائمة مراقبة، إظهار/إخفاء اللوحات، تبويبات سفلية.
- **الإعدادات:** المظهر واللغة والشريط الجانبي (تعمل وتُحفظ محلياً).
- بقية الوحدات (23 وحدة): صفحات صريحة تقول "لم يُنفَّذ بعد" مع رقم المرحلة المخططة لها. لا بيانات مزيّفة فيها.

## ما لم يُنفَّذ بعد (حسب خارطة الطريق المعتمدة)

أدوات الرسم (فيبوناتشي...)، المؤشرات الفعلية، لوحة التحكم القابلة للسحب والتخصيص، محرر Pine (Monaco)، منشئ الاستراتيجيات، الاختبار الخلفي، الإعادة، التداول الورقي والحي، المخاطر، الذكاء الاصطناعي، الإشعارات الفعلية، وكل ما يحتاج Backend. راجع `docs/PROJECT_STATUS.md`.
